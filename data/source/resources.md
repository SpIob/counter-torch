# Challenge resources (from the Space Apps challenge page, available Nov 13)

Status column says what an agent's web tool can actually read. "JS app" means the page is rendered by JavaScript and a plain fetch returns an empty shell.

## Data
| Resource | URL | Agent-readable? |
|---|---|---|
| PSI Data Repository, combustion search | https://psi.nasa.gov/physci/repo/search?q=combustion | No (JS app). Needs a browser or a found API. |
| PSI on the AWS Registry of Open Data | https://registry.opendata.aws/nasa-psi | Yes. Public S3 bucket `nasa-psi`, region us-west-2, no account needed. Registry text names only DSI and OASIS datasets, so combustion presence is unconfirmed. |
